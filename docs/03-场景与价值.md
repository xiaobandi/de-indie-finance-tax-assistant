# 03 · 场景与价值

## 谁在用

个体户/OPC 形态的全体独立开发者，尤其有跨境收款者

## 三个典型场景

### 场景 A：收入流水整理
- **触发**：定时（每月）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：Stripe/Paddle/支付宝流水导入 → 发票归类 → 月度台账
- **收益**：省 2h/月 ≈ ¥160

### 场景 B：报税节点提醒
- **触发**：定时
- **之后**：按主体类型生成年度合规日历 → 节点前 7/3/1 天三级提醒
- **收益**：防罚款止损，单次漏报代价 ≥¥500

### 场景 C：合规文档生成
- **触发**：人工
- **之后**：隐私政策/备案材料/用户协议模板填充 → 人工审校
- **收益**：省 3h/次 ≈ ¥240

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 防漏报罚款 + 月省 3-5h，作为全家桶信任组件拉高续费 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
